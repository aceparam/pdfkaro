## How to compress a PDF

1. Choose the PDF file you want to make smaller. You can also drop it anywhere on this page, or paste it.
2. Press “Compress and download”. There are no settings to choose.
3. When the compressed file is ready, the page shows its new size next to the old one. Press Download.

## Questions

### What is made smaller?

Pictures in the file. A JPG picture that is sharper than it needs to be for its page is scaled down and saved again. A picture stored without loss, such as a screenshot or a drawing, is scaled down and stored without loss again, so it never gets the blur of a JPG. Then the whole file is written again more tightly, and pictures and fonts that nothing uses are removed.

### Why is my file still large after compressing?

Some files have little this tool can make smaller. A file of text only may already be packed tightly. Fonts take space, and this tool keeps every font that is used. Pictures in CMYK colour, black and white scans and JPEG 2000 pictures are left as they are. If the file could not be made at least a little smaller, the page says so and gives you no new file.

### Will the pages look worse?

On screen they should look the same. Pictures that were made smaller can look slightly less sharp when you zoom in a long way.

### Does anything else change?

Pages, text, links, form fields and what was typed in them, bookmarks, attached files and the document's details are kept. The file is written afresh, so earlier saved versions stored inside it are not kept, and a digital signature will no longer be valid.

### Can I use a PDF that has a password?

Yes, if you know the password. The page asks for it, and the password stays in your browser. The compressed file has the same password and the same restrictions as the file you chose.

### Is my file uploaded?

No. The file is read and compressed in your browser, on your device. Nothing is sent anywhere. Once you choose a file, the page loads only the parts of this site it needs to do the work, and they carry nothing from your file. When you press Start again or leave the page, the page forgets the file and the result.

### Is there a limit on size?

There is no fixed limit. The work happens on your device, so a very large file can be slow, and a phone may run out of memory. The page warns you when the file is more than 100 MB, or has more than 20,000 pages.

### What if the file is damaged?

The page says it cannot read the file. You can choose another file.
