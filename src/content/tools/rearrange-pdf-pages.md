## How to reorder the pages of a PDF

1. Choose the PDF file you want to reorder. You can also drop it anywhere on this page, or paste it.
2. Each page is shown. Press “Earlier” or “Later” under a page to move it one place, or drag it onto another page with a mouse.
3. Press “Reorder and download”.
4. When the new file is ready, press Download.

## Questions

### Is my file uploaded?

No. The file is read and the new file is made in your browser, on your device. Nothing is sent anywhere. Once you choose a file, the page loads only the parts of this site it needs to do the work, and they carry nothing from your file. When you press Start again or leave the page, the page forgets the file, the order you made and the result.

### How do I move a page with a keyboard or on a phone?

Each page has two buttons, “Earlier” and “Later”. Each press moves the page one place, and the page says where it now is. On a long file this can take many presses; on a computer, dragging a page onto another is quicker for long moves.

### Is my original file changed?

No. The pages are copied into a new file in the order you made. Your original file stays as it was. Reordering report.pdf gives report-reordered.pdf.

### What happens to bookmarks and attached files?

Every bookmark is kept and still points to the same page, wherever that page now is. The list of bookmarks keeps its own order, so it may no longer match the order of the pages. Files attached to the document are kept, and text, links and form fields stay on their pages.

### Does a screen reader follow the new order?

Not always. In a file with accessibility tags, the tags keep the original reading order, so a screen reader may still read the pages in the order they had before.

### Can I use a PDF that has a password?

Yes, if you know the password. The page asks for it, and the password stays in your browser. The new file has no password and no restrictions. You can add a password afterwards.

### Is there a limit on size?

There is no fixed limit. The work happens on your device, so a very large file can be slow, and a phone may run out of memory. The page warns you when the file is more than 100 MB, or has more than 20,000 pages.

### What if the file is damaged?

The page says it cannot read the file. You can choose another file.
