## How to repair a damaged PDF

1. Choose the PDF file. You can also drop it anywhere on this page, or paste it.
2. If the file needs a password to open, type it.
3. Press “Repair and download”. When the new file is ready, press Download.
4. Open the new file and check it before you rely on it.

## Questions

### What kinds of damage can it fix?

Files that were cut off part way, such as an interrupted download; files whose table of contents at the end points to the wrong places or is missing; files with extra bytes before or after the PDF; and files with a few damaged parts. It reads the file object by object from the start and leaves out what makes no sense. It cannot fix every file.

### Why are some pages missing or blank?

Only what could still be read is kept. A page that was lost in the damage cannot be brought back. A page whose drawing was lost is kept as a blank page of its size, and a drawing that was damaged part way keeps what could still be read.

### Why does some of the file look older?

If the file was changed and saved again, and that last save was damaged, the new file can show parts of the earlier version.

### Why does the new file have no password?

A password is needed only to read the damaged file. The new file has no password and no restrictions, even if the file you chose had them.

### My file still does not open in one program

Try opening it in another program. If the new file does not open either, or something is missing, the damage may be beyond what this tool can recover. If you have another copy of the file, try that one.

### It says my file has no damage

Then this tool found nothing to repair and made no new file. You can use your file as it is.

### Is my file uploaded?

No. The file is repaired in your browser, on your device. The file and its password are not uploaded.

### What changes and what stays?

Text, links, form fields and what was typed in them, notes, bookmarks, attached files, accessibility tags and the document’s details that could be read are kept. The file is written afresh, so earlier saved versions stored inside it are not kept, and a digital signature in it will no longer be valid.
