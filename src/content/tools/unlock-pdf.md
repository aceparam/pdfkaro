## How to remove a password from a PDF

1. Choose the PDF file. You can also drop it anywhere on this page, or paste it.
2. If the file needs a password to open, type it.
3. Press “Remove protection and download”. When the new file is ready, press Download.

## Questions

### Is my file uploaded?

No. The protection is removed in your browser, on your device. The file and the password are not uploaded. The page lets go of the password once the new file is ready, and of both when you press Start again, close the tab or go to another page in it.

### I have forgotten the password

This tool cannot help. It removes only a password you type. It does not guess, crack or recover one.

### My file opens, but will not let me print or copy

Choose it. No password is asked for, and the print, copy and edit restrictions are removed. Such restrictions are a request to PDF readers, not a lock, so any program can open the file. Remove them only from a file you are allowed to change.

### Which password do I type?

The one that opens the file. If the file also has a separate password for permissions, that works too.

### It says my file has no password or restrictions

Then there is nothing to remove, and no new file is made. You can use your file as it is.

### It says my file is saved in a way this tool cannot read

It is protected in a way this tool cannot remove, such as with a certificate. Ask whoever sent it for a copy without this protection.

### What changes and what stays?

Pages, text, links, form fields and what was typed in them, notes, bookmarks, attached files, the document’s details and accessibility tags are kept. The file is written afresh, so earlier saved versions stored inside it are not kept, and a digital signature in it will no longer be valid.

### Is my original file changed?

No. Removing the password from report.pdf gives a new file, report-unprotected.pdf, which anyone who has it can open. Keep it where only you can reach it if what it holds is private.
