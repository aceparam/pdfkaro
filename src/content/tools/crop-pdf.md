## How to crop the margins of a PDF

1. Choose the PDF file. You can also drop it anywhere on this page, or paste it.
2. Press “Crop and download”. Each page is cut to what is drawn on it.
3. When the new file is ready, press Download.

## Questions

### Is my file uploaded?

No. The file is read and the new file is made in your browser, on your device. Nothing is sent anywhere. When you press Start again or leave the page, the page forgets the file and the result.

### How does it decide where to cut?

Anything on the page that is not white counts, even a light grey line or an empty form box. About 5 mm is left around it on an A4 page. Each page is cut on its own.

### Why are my pages different sizes now?

Each page is cut to what is on it, so a page with a short note becomes smaller than a full page. Your reader may show them at different sizes.

### Why was a page, or my scan, not cut?

A blank page is left as it is, and so is a page whose content already reaches its edges. Pages with grey or dark edges, such as many scans, are left too. The tool also leaves a page as it is when it cannot be sure where everything on it is, for example text in a font the file does not include.

### Is what I cut off gone?

No. It is hidden, but it is still in the file. Anyone who has the file can get it back, and some programs can still find, copy or read aloud its text. Cropping is not a way to hide something private. This site has no tool yet that removes it for good.

### Can I choose how much to cut?

Not yet. Each page is cut to what is drawn on it, with a small margin.

### Do links, forms and bookmarks still work?

Yes. Text, links, form fields, notes, bookmarks, attached files and the document's details are kept. But the new file is written afresh, so earlier saved versions stored inside the original are not kept, and a digital signature will no longer be valid. Check the new file before you send it.

### Can I use a PDF that has a password?

Yes, if you know the password. The page asks for it, and the password stays in your browser. The new file has no password and no restrictions.

### Is my original file changed?

No. You get a new file. Cropping report.pdf gives report-cropped.pdf.

### Is there a limit on size?

There is no fixed limit, but every page is looked at, so a long file takes a while. The page warns you when the file is more than 100 MB, or has more than 20,000 pages.
