## How to split a PDF file

1. Choose the PDF file you want to split. You can also drop it anywhere on this page, or paste it.
2. Each page is shown. Press "Cut after" under a page to start a new file after it. Press it again to take the cut away.
3. Press Split and download.
4. When the files are ready, press Download. Several files come in one zip.

## Questions

### Is my file uploaded?

No. The file is read and split in your browser, on your device, and several new files are put into one zip there too. It is not sent anywhere. Once you choose a file, the page loads only the parts of this site it needs to do the work, and they carry nothing from your file. When you press Start again or leave the page, the page forgets the file, your cuts and the result.

### How do I choose where to cut?

Each page has a "Cut after" button under it, except the last page. A cut after page 3 means pages 1 to 3 become one file and the next file starts at page 4. The line above the pages says how many files you will get.

### What do I get if I mark no cuts?

One file for each page. A 12-page PDF gives 12 files.

### How are the new files named?

They are named after your file. Splitting report.pdf gives report-split.zip, which holds report-part-1.pdf, report-part-2.pdf and so on, numbered in page order. A one-page file comes back as report-split.pdf.

### What happens to bookmarks and attached files?

Each new file keeps the bookmarks that point to its own pages, and no others. Files attached to the document go with the first new file only. An attachment placed on a page stays on that page, in whichever file holds the page. Text, links and form fields stay as they were. Every new file keeps the document's title, author and other details, and its accessibility tags, which can describe pages that went into other files.

### Can I split a PDF that has a password?

Yes, if you know the password. The page asks for it when it reads the file, and the password stays in your browser. The new files have no password and no restrictions, even if your file had them. You can add a password afterwards.

### Is there a limit on size?

There is no fixed limit. The work happens on your device, so a very large file can be slow, and a phone may run out of memory. The page warns you when the file is more than 100 MB. One zip can hold at most 65,535 files and 4 GB; if a split would make more, the page asks you to mark cuts.

### What if the file is damaged?

The page says it cannot read the file. You can choose another file.
