## How to turn a PDF grey

1. Choose the PDF file. You can also drop it anywhere on this page, or paste it.
2. Press “Convert to grayscale and download”.
3. When the new file is ready, press Download.

## Questions

### Is my file uploaded?

No. The new file is made in your browser, on your device. Nothing is sent anywhere.

### Can I still search and copy the text?

Yes. The text is not turned into a picture, so you can still search, select and copy it.

### Will this make my file smaller?

No. It stays about the same size, because the original colours stay stored underneath. To make it smaller, use Compress PDF, or compress it to a target size.

### Are the colours really gone?

They show grey on screens and print grey on office printers. But the colour values are still in the file. A program that takes pictures out of a PDF may get them in colour, a program that checks a file for colour may find it, and a print shop’s tools may list three or four extra inks.

### What stays in colour?

The grey is the PDF standard’s mix of red, green and blue, and colours made for printing (CMYK) and colour-managed colours come out close to how they looked. These are left in colour: spot colours; Lab colours; colours with unusual colour profiles; JPEG 2000 pictures; small pictures stored inside a page’s drawing instructions; soft masks, which set how see-through something is; some notes’ looks and patterns that carry no settings of their own; parts of a page that could not be read with certainty; colours in notes’ text styles or set by scripts; drawing in older XFA forms; colour glyphs in fonts; and attached files.

### Do links, forms and bookmarks still work?

Yes. Links, form fields and what is typed in them, notes, bookmarks and attached files are kept, and the colours of fields and notes turn grey too. The new file is written afresh, so a digital signature will no longer be valid, and earlier saved versions stored inside the original are not kept.

### Why did I get no new file?

Nothing in the file was turned grey. Its pages may already use only grey, or their colours may all be kinds this tool leaves as they are.

### Why did it stop on one page?

A page with very large drawing instructions, such as a very detailed map or plan, cannot be converted here. The page shows an error naming that page. Delete that page, or split the file, and convert the rest.

### What happens to a password?

If the file needs one, the page asks for it. The password stays in your browser. The new file has no password and no restrictions.

### Is my original file changed?

No. You get a new file. Converting report.pdf gives report-grayscale.pdf.
