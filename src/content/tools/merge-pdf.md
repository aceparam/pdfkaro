## How to merge PDF files

1. Choose the PDF files you want to join. You can choose several at once, add more later, or drop them anywhere on this page.
2. Put them in the order you want. Use Move up and Move down, or drag them with a mouse.
3. Press Merge and download.
4. When the new file is ready, press Download.

## Questions

### Are my files uploaded?

No. The files are read and joined in your browser, on your device. They are not sent anywhere. When you press Start again or leave the page, the page forgets them.

### Is there a limit on size or number of files?

There is no fixed limit. The work happens on your device, so very large files can be slow, and a phone may run out of memory. The page warns you when the files add up to more than 100 MB.

### Can I merge a PDF that has a password?

Yes, if you know the password. The page asks for it when it reads the file, and the password stays in your browser. The merged file has no password and no restrictions, even if one of the files you chose had them. If you want the new file protected, add a password to it afterwards.

### What happens to bookmarks and attachments?

Bookmarks and attached files come from the first file only. Those in the other files are left out. Every page of every file is kept, with its text, links and form fields. If you need a file's bookmarks, put that file first.

### What if a file is damaged?

The page says which file it cannot read. You can leave that file out and merge the rest.

### Why is the merged file larger than I expected?

It is about the size of all the files together, because every page is kept as it was. Nothing is made smaller along the way.
