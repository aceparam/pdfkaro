## How to get a PDF under 100 KB

1. Pick the PDF that is too large for the form or portal. Dropping it on this page, or pasting it, works as well.
2. Press “Compress to 100 KB and download”. Nothing needs setting first.
3. Read the heading above the result. It tells you whether the new file is at most 100 KB, then press Download.

## Questions

### Can every PDF be made 100 KB or smaller?

No. 100 KB is a tight limit: a page or two of text fits easily, and so does a short scan, but a long scan of many pages often does not. This tool lowers the sharpness of the pictures in steps and stops at a floor, 72 pixels to the inch, where small print in a scan still reads. It never goes below that floor.

### What happens if it still does not fit?

You get the smallest file this tool could make, with its size and a plain sentence saying it is over 100 KB. If even that file is not at least 1% smaller than yours, there is no new file, and the page tells you so. To get under the limit after that, remove pages you do not need with Delete pages, or split the file and send the parts.

### What exactly does 100 KB mean here?

100,000 bytes. Some forms count a kilobyte as 1,000 bytes and some as 1,024, so aiming for 100,000 suits both kinds. Because of this, a file shown as 98 KB on this page can still be over the target and still be compressed.

### Which parts get smaller?

Only pictures. Text, lines, fonts and links stay exactly as they were. Pictures stored without loss, such as screenshots, are scaled down but kept without loss. Pictures in CMYK colour, black and white scans, JPEG 2000 and a few rarer kinds are not touched, which is why some files stay large.

### My file is already small. What then?

When the file you pick is 100 KB or less, the main button stays unavailable and says there is nothing to do. Use the file you have.

### Does it send my file anywhere?

No. All the work runs inside your browser on this device. Nothing about the file, its name or its password leaves it.

### Will a password or a signature survive?

A file you open with its password keeps that password and its restrictions. A digital signature does not survive: the file is written again, and earlier saved versions inside it are dropped.
