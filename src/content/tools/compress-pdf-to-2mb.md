## Compressing a large PDF to 2 MB

1. Choose the big PDF, such as an annual report, a thesis with figures or a set of scanned chapters. You may drop it on the page or paste it.
2. Next, press “Compress to 2 MB and download”. A file of many megabytes can take a while, and the progress line shows how far it has got.
3. When it finishes, press Download. The result shows the new size next to the original one.

## Questions

### Why might a file far over 2 MB not fit?

Pictures are the only thing this tool shrinks. A long document can carry several megabytes of fonts, or files attached inside it, and those keep their full size. If the text and fonts alone weigh more than 2 MB, no amount of picture work brings the whole file under the limit. Some pictures are not touched either: CMYK photos, black and white scans, JPEG 2000 images, pictures with a palette and masks keep their size.

### How sharp do the pictures stay?

As sharp as the limit allows. The tool begins at 150 pixels to the inch with good quality and only moves to stronger steps if the file would not fit. For 2 MB, many reports never go past the first step or two.

### Should I use Compress PDF instead?

Use Compress PDF when you just want a smaller file and have no fixed limit: it makes one careful pass. Use this page when a portal or email has a hard ceiling of 2 MB and you need the file under it.

### How does this page count 2 MB?

As 2,000,000 bytes. Since some limits mean 2,000,000 bytes and some mean 2,097,152, the lower number is the safe one. So the page may still compress a file whose size it shows as 2.0 MB.

### What if the result is still over 2 MB?

The page says so, names the size of the smallest file it made, and lets you download it. To go further, take out pages with Delete pages, or use Split PDF and send the file in parts.

### Is a large file uploaded somewhere to be compressed?

No. However large it is, the file is compressed by your browser on your own device. A phone may run short of memory on a very large file; the page warns you above 100 MB.

### What happens to a password, a form or a signature?

A password and its restrictions remain. Form fields and what was typed in them remain. A digital signature becomes invalid, because the file is written afresh.
