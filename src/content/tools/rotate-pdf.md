## How to rotate PDF pages

1. Choose the PDF file whose pages you want to turn. You can also drop it anywhere on this page, or paste it.
2. Each page is shown. Press “Turn left” or “Turn right” under a page to turn it a quarter, or press “Turn every page left” or “Turn every page right” to turn them all.
3. Press “Turn and download”.
4. When the new file is ready, press Download.

## Questions

### Is my file uploaded?

No. The file is read and the new file is made in your browser, on your device. Nothing is sent anywhere. Once you choose a file, the page loads only the parts of this site it needs to do the work, and they carry nothing from your file. When you press Start again or leave the page, the page forgets the file, the turns you made and the result.

### Can I turn just one page?

Yes. Each page has its own “Turn left” and “Turn right”. Each press turns it a quarter, and its picture and the words under it show how far it is from how it was. To turn a scan that came out sideways, turn every page at once.

### Can I straighten a slightly crooked scan?

No. Pages turn by quarters only: a quarter, a half or three quarters. Straightening a page by a few degrees would change what is drawn on it, which this tool does not do.

### Does anything else in the file change?

No. Only the way each page faces changes. Text, links, form fields, notes, bookmarks, attached files, the document's details and any hidden text stay as they were. The file is not cleaned of anything.

### Is my original file changed?

No. You get a new file. Your original file stays as it was. Turning the pages of report.pdf gives report-rotated.pdf.

### Can I use a PDF that has a password?

Yes, if you know the password. The page asks for it, and the password stays in your browser. The new file has no password and no restrictions. You can add a password afterwards.

### Is there a limit on size?

There is no fixed limit. The work happens on your device, so a very large file can be slow, and a phone may run out of memory. The page warns you when the file is more than 100 MB, or has more than 20,000 pages.

### What if the file is damaged?

The page says it cannot read the file. You can choose another file.
